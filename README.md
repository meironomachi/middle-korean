# 중세 한국어 사전

후기 중세국어(15~16세기)의 어휘·조사·어미·문법을 **사람이 읽고 기계가 쓸 수 있는** 형태로 모읍니다.
최종 목표는 이 데이터를 바탕으로 중세국어 번역기를 만드는 것입니다.

## 지금 들어 있는 것

| 파일 | 내용 | 규모 |
|---|---|---|
| `data/lexicon.json` | 표제어, 품사, 뜻풀이, 예일식 로마자 표기, 방점 찍힌 표기, 현대어 대응, 출전 | 969항목 |
| `data/grammar.json` | 조사·선어말어미·어말어미·연결어미·전성어미와 이형태 선택 규칙 | — |
| `data/phonology.json` | 옛 글자·어두자음군·8종성법·연철/분철·모음조화 변환 규칙 | — |
| `corpus/*.json` | 문헌 원문 말뭉치 (방점 그대로) | 3문헌 270단락 |

### `lexicon.json` 한 항목의 생김새

```json
{
  "headword": "ᄒᆞ다",
  "senses": [
    { "pos": "Verb",
      "glosses": ["to do", "to say"],
      "written": "ᄒᆞ〮다〮",
      "yale": "hǒta" }
  ],
  "modern": ["하다"],
  "attested": [{ "work": "석보상절", "year": 1447 }]
}
```

- `written` — 방점(`〮` 거성, `〯` 상성)까지 찍힌 표기. 표제어와 다를 때만 들어감
- `yale` — 예일식 로마자 표기. 성조가 함께 표시됨
- `modern` — 현대 한국어로 이어진 말
- 현재 현대어 연결 592개, 예일식 표기 578개, 방점 표기 677개, 출전 186개
- 옛 글자(ㅸ ㆆ ㆁ ㆅ 등) 39개와 방점 기호(〮 〯) 2개도 표제어로 들어 있음

### `grammar.json` 의 규칙

조사와 어미는 앞말에 따라 꼴이 갈립니다. 그 조건을 사람 말(`env`)과 기계가 판정할 수 있는
형태(`rule`) 두 가지로 함께 적었습니다.

```json
{ "form": "ᄋᆞᆯ",
  "env": "양성 모음 + 자음으로 끝나는 체언 뒤",
  "rule": { "harmony": "yang", "ends": "consonant" },
  "examples": [{ "mk": "門ᄋᆞᆯ 다 ᄌᆞᄆᆞ고", "ko": "문을 다 잠그고" }] }
```

`rule` 에 쓰는 열쇳말은 `grammar.json` 의 `meta.rule_keys` 에 정리돼 있습니다.

## 만드는 법

```bash
python3 tools/harvest.py   # 위키낱말사전에서 표제어와 본문을 받음 (이어받기 됨)
python3 tools/parse.py     # 받은 본문에서 중세 한국어 부분만 떼어 사전 항목으로
```

`harvest.py` 는 배치마다 저장하므로 중간에 끊겨도 다시 돌리면 이어서 받습니다.
위키미디어가 속도 제한을 걸기 때문에 호출 간격을 두고 재시도합니다.

## 옛한글 글꼴

`ᄒᆞ다`, `ᅀᆞᇦ` 처럼 현대 한글에 없는 글자는 유니코드 **한글 자모 영역(U+1100~)** 의
첫가끝 조합으로 적혀 있습니다. 이 글자들이 네모로 보인다면 옛한글을 지원하는 글꼴
(함초롬바탕, 본명조/본고딕 옛한글 등)이 필요합니다.

## 사전 페이지

`index.html` 이 `data/` 를 읽어 찾아보기 화면을 만듭니다. 중세어·현대어·뜻(영어) 어느 쪽으로도
찾을 수 있고, 조사·어미 표도 함께 봅니다. 깃허브 페이지로 그대로 띄울 수 있습니다.

옛한글은 설치된 글꼴을 먼저 씁니다(`local()`). `fonts/` 에 웹폰트를 넣어 두면 그것도 씁니다.
글꼴 파일은 재배포 조건을 확인하기 전이라 저장소에 넣지 않았습니다.

### 지금 맞물리는 정도

사전 969개 가운데 **169개**를 문헌에서 찾았고, 말뭉치 어절의 **19%**만 사전으로 설명됩니다.
나머지는 대부분 아직 사전에 없는 낱말(`몯`, `모딘`, `아바님`, `니ᄅᆞ시니`)이라,
어휘를 늘리면 이 비율이 올라갑니다.

맞대어 보는 방식은 **어절 앞에서부터 가장 길게 맞는 표제어를 찾는** 수준입니다.
용언은 `-다` 를 뗀 어간도 함께 올려 `ᄒᆞ다` 가 `ᄒᆞ시니` 를 알아봅니다.
형태소 분석이 아니라서 틀리는 자리가 있습니다.

## 형태소 분석

`tools/analyze.py` 가 어절을 '어간/체언 + 조사/어미'로 쪼갭니다.
중세국어는 앞 글자 받침을 뒤 글자 첫소리로 내려 적는 **연철**이라, 글자 그대로는 사전에서 못 찾습니다.
받침을 제자리로 돌려놓고 찾습니다.

```bash
$ python3 tools/analyze.py "나랏 말ᄊᆞ미 中國에"
  나랏      나라 + ㅅ      [표제어 나라 / 조사 관형격 · 받침조사]
  말ᄊᆞ미    말ᄊᆞᆷ + 이     [표제어 말ᄊᆞᆷ / 조사 주격 · 연철]
  中國에     中國 + 에      [표제어 中國 / 조사 부사격 처소 · 직접]

$ python3 tools/analyze.py --eval      # 말뭉치에서 얼마나 쪼개지는지
```

쪼개는 방법:

| 방법 | 하는 일 | 예 |
|---|---|---|
| 직접 | 글자 그대로 어간 + 어미 | `中國에` = 中國 + 에 |
| **연철** | 끝 음절 초성을 앞 음절 받침으로 되돌림 | `말ᄊᆞ미` = 말ᄊᆞᆷ + 이 |
| **어미 연쇄** | 어미가 겹쳐 붙은 것을 차례로 떼어 냄 | `ᄒᆞ시니` = ᄒᆞ + 시 + 니 |
| **ㅎ종성체언** | 받침 뒤에 한 번 더 붙는 ㅎ 을 다룸 | `하ᄂᆞᆯ히` = 하ᄂᆞᆯ + 이 |
| 받침조사 | 받침으로 붙은 조사를 뗌 | `나랏` = 나라 + ㅅ |
| **불규칙** | ㅸ→ㅂ, ㅿ→ㅅ, ㄹ→ㄷ 으로 되돌림 | `도ᄫᅡ` = 돕 + 아 |
| 그대로 | 어미 없이 표제어 자체 | `불휘` |

같은 꼴이 여러 자리에 쓰이면 놓인 자리로 가린다. `니` 는 선어말어미도 연결어미도 되는데,
맨 끝에 오면 연결어미로 읽는다.

### 지금 얼마나 쪼개지나

말뭉치 어절 28,480개 가운데 **39.8%**를 설명합니다.

사전을 969 → 9,264항목으로 늘리면서 22.9% → 34.4%, 어미 연쇄와 ㅎ종성체언을 다루면서
34.4% → 41.4% 가 되었습니다. 그 뒤 말뭉치를 5천 → 2만 8천 어절로 넓히면서 39.8% 로
조금 내려갔는데, 글이 늘면 모르는 낱말도 함께 늘기 때문입니다.

못 쪼갠 것의 70% 는 **어간을 모르는** 경우입니다. 들여다보면 `셰존`(世尊), `슈따ᇙ`,
`져텬` 같은 불경 고유명사가 많습니다.

## 어절 분석 (사이트)

`analyze.js` 가 `tools/analyze.py` 를 브라우저로 옮긴 것입니다. 사이트의 **어절 분석** 탭에서
문장을 넣으면 그 자리에서 쪼갭니다. 서버는 쓰지 않습니다 — 사전과 문법 파일을 이미
받아 두었으므로 그대로 씁니다.

```
ᄒᆞ시니ᅌᅵᆺ고  →  ᄒᆞ + 시 + 니 + ᅌᅵᆺ고
                어간   주체 높임   시제·서법   의문형(설명의문·ᄒᆞ쇼셔체)
```

두 쪽 규칙이 어긋나면 안 되므로, 말뭉치에서 나온 어절 13,922개를 두 구현에 모두 넣어
결과가 글자까지 같은지 확인했습니다 (100%). 한쪽을 고치면 다른 쪽도 고쳐야 합니다.

## 상대 높임 등급

듣는 사람을 얼마나 높이는지에 따라 종결어미가 갈립니다. 현대어 `-습니다` 처럼 한 덩어리가
아니라 `-ᅌᅵ-`(상대 높임)가 따로 끼어들어 `-ᅌᅵ다 / -ᅌᅵᆺ가` 를 만듭니다.

| 등급 | 현대어 | 평서 | 의문 · 판정 | 의문 · 설명 | 명령 | 청유 |
|---|---|---|---|---|---|---|
| **ᄒᆞ쇼셔체** | 합쇼체 | -ᅌᅵ다 (95) | -ᅌᅵᆺ가 (19) | -ᅌᅵᆺ고 (34) | -쇼셔 (21) | -사이다 (0) |
| **ᄒᆞ야쎠체** | 하오체 쯤 | -ᅵᇰ다 (0) | -ᅵᆺ가 (0) | -ᅵᆺ고 (0) | -야쎠 (0) | — |
| **반말 등분** | 반말 | `-리 / -니` 로 끝맺음 — 평서·의문 두루 | | | | |
| **ᄒᆞ라체** | 해라체 | -다 (370) | -녀 · -니아 · -ㄴ가 (103) | -뇨 · -니오 · -ㄴ고 (30) | -라 (211) | -져 (46) |

세로로 내려갈수록 듣는 사람을 덜 높입니다. 괄호 안은 말뭉치 11문헌 28,185어절에서
`tools/analyze.py` 가 센 횟수입니다. ᄒᆞ라체에는 주어가 2인칭일 때 쓰는 의문형 `-ㄴ다` 가
더 있습니다.

판정의문(예·아니오로 답)과 설명의문(의문사에 답)을 어미로 가리는 것도 현대어에 없는
특징입니다. `ᅡ` 계열이 판정, `ᅩ` 계열이 설명입니다.

```
ᄒᆞᄂᆞᆫ가  판정의문 — 하는가?         許ᄒᆞ시니ᅌᅵᆺ가  내훈/권3
ᄒᆞᄂᆞᆫ고  설명의문 — 무엇을 하는가?   ᄒᆞ리ᅌᅵᆺ고      석보상절/권23
```

```bash
python3 tools/analyze.py 'ᄒᆞ시니ᅌᅵᆺ고'
#  ᄒᆞ + 시 + 니 + ᅌᅵᆺ고
#  [어간 ᄒᆞ다 / 주체 높임 · 시제·서법 · 의문형(설명의문·ᄒᆞ쇼셔체)]
```

ᄒᆞ야쎠체는 `-ᅵᇰ-·-ᅵᆺ-` 가 첫소리 없이 앞 음절 받침에 붙어서 글자만으로는 찾지 못합니다.
말뭉치에도 나오지 않습니다. 반말 등분도 끝맺는 `-니` 와 연결어미 `-니` 가 글자가 같아
가리지 못합니다. ᄒᆞ라체 `-다·-라·-가·-고` 는 조사·연결어미와 겹쳐서 앞 어미를 보고
추정만 합니다.

출처는 한국민족문화대백과사전 '경어'(E0002676)·'공손법'(E0079632) 항목입니다. 두 항목은
평서·의문·명령형만 다루므로 청유형은 학교 문법의 정리를 따랐습니다.

## 변환기

`tools/convert.py` 가 `phonology.json` 의 규칙과 `lexicon.json` 을 함께 써서
중세국어 표기를 현대 한글로 1차 변환합니다. 사전에 있는 말은 사전을 먼저 봅니다.

```bash
python3 tools/convert.py "불휘 기픈 남ᄀᆞᆫ"      # → 뿌리 기픈 남근
python3 tools/convert.py --test                  # 규칙이 어디까지 닿는지 확인
```

규칙이 닿는 자리와 못 닿는 자리를 `--test` 가 나눠서 보여 줍니다.
`ᄭᅮᆷ→꿈`, `ᄆᆞᅀᆞᆷ→마음` 처럼 규칙만으로 가는 것이 있고,
`ᄠᅳᆮ→뜯`(8종성법 때문에 '뜻'까지 못 감), `ᄀᆞᄅᆞᆷ→가름`('가람'은 어휘가 바뀐 말)처럼
사전이 받아 줘야 하는 것이 있습니다.

본문이 `<pages index="...">` 로 PDF 쪽 문서에서 전치되는 문헌이 많습니다.
API 가 이걸 펼쳐 주지 않으므로 쪽 문서를 따로 받아 붙입니다.

용비어천가는 장마다 **한문 / 중세국어 / 현대어**가 나란히 있어 대역 자료로 쓸 수 있습니다.

```bash
python3 tools/corpus.py          # 위키문헌에서 받아 corpus/ 에 저장
python3 tools/attest.py          # 사전과 맞대어 용례와 미등재 어휘를 뽑음
```

`attest.py` 가 만드는 것:
- `corpus/attestations.json` — 사전 표제어가 문헌 어디에 쓰였는지 (어절과 줄 전체 포함)
- `corpus/unknown.json` — 말뭉치에는 있는데 사전으로 설명되지 않는 꼴. 어휘를 늘릴 실마리

형태소 분석이 아니라서 틀리는 자리가 있습니다.

## 아직 안 된 것

- 아직 못 읽은 1항목 (`뵈ᄧᅡᇰ이`)
- 말뭉치 보강 — 용비어천가는 125장 가운데 42장만 위키문헌에 전사돼 있음.
  석보상절·두시언해·월인석보는 위키문헌에 머리말만 있고 본문이 없음
- 기본 옛 글자 `ㆍ`(아래아) `ㅿ`(반치음) — 위키낱말사전의 중세 한국어 표제어 분류에 없어 따로 채워야 함
- `phonology.json` — ㆍ→ㅏ/ㅡ, ㅿ→∅, ㅸ→ㅗ/ㅜ, 어두자음군→된소리 같은 표기 변환 규칙
- 사람이 읽는 사전 페이지
- 우리말샘·세종계획 말뭉치 등 국내 자료 보강
